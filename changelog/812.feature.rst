Added :class:`pluggy.PluginManagerSnapshot` for immutable, point-in-time snapshots of a :class:`pluggy.PluginManager` and isolated clone restoration via :meth:`PluginManager.snapshot() <pluggy.PluginManager.snapshot>`, :meth:`PluginManagerSnapshot.restore() <pluggy.PluginManagerSnapshot.restore>` and :meth:`PluginManager.restore_snapshot() <pluggy.PluginManager.restore_snapshot>`. A clone is a fully independent manager preserving hookspecs, plugin identities, blocked names, hook implementation ordering and :ref:`historic <historic>` call history; building it runs no plugin callbacks, inherited historic events replay to newly registered plugins at most once, and clone activity never leaks back to the source manager or other clones. Invalid snapshots raise a :class:`pluggy.SnapshotError` subclass before any plugin callback runs. Added the read-only :attr:`PluginManager.manager_version <pluggy.PluginManager.manager_version>` structural counter.
